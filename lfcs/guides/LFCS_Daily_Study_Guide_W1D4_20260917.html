🐧 LFCS Core Concepts Deep Dive: Special Permissions: SUID, SGID & Sticky Bit

Special permissions extend the standard DAC permissions for specific operational security patterns.

  • SUID (4000): Executes as the file owner rather than the calling user (e.g. passwd writing to /etc/shadow).
  • SGID (2000): On files, executes with group privileges. On directories, newly created files automatically inherit the parent directory's group.
  • Sticky Bit (1000): Appended to shared directories like /tmp so users cannot delete or rename each other's files.
/usr/bin/passwd (rwsr-xr-x) chmod u+s /path/to/binary Symbol: 's' (or 'S' if owner not executable) SGID (Set Group ID: 2000) • On directory: new files inherit dir group • Crucial for shared team folders! chmod g+s /shared/team Octal: chmod 2775 /shared/team STICKY BIT (1000) • Prevents users from deleting others' files • Only file owner or root can remove chmod +t /tmp Representation: drwxrwxrwt (1777)

📋 Scenario Overview

Practice scenario aligned with your official certification preparation schedule. Complete all tasks under exam conditions.

🎯 Candidate Tasks
📌 Task 1: Collaborative Shared Directory with SGID
  1. Create a group named marketing.
  2. Create directory /opt/campaigns.
  3. Set ownership of /opt/campaigns to user root and group marketing.
  4. Enforce permissions such that:
  • Group members have full read, write, and execute permissions (rwx).
  • Others have zero permissions (---).
  • Any new file or directory created inside automatically inherits the group marketing (SetGID bit).
📌 Task 2: Secure Public Drop Directory with Sticky Bit
  1. Inside /opt/campaigns, create a directory incoming.
  2. Configure permissions on /opt/campaigns/incoming with the Sticky bit (1777 or 1770):
  • Only the file owner or root can delete or rename files inside incoming.
📌 Task 3: World-Writable File Security Audit
  1. Search /var/log for any world-writable files (-perm -002).
  2. Save the list of matched paths to /var/tmp/world_writable_audit.txt.

✅ Step-by-Step Grader Solution Walkthrough
📌 Tasks & Official Solution
  1. Create group and configure SGID directory:
sudo groupadd -f marketing
sudo mkdir -p /opt/campaigns
sudo chown root:marketing /opt/campaigns
sudo chmod 2770 /opt/campaigns
  1. Configure Sticky bit directory:
sudo mkdir -p /opt/campaigns/incoming
sudo chown root:marketing /opt/campaigns/incoming
sudo chmod 1770 /opt/campaigns/incoming
  1. World-writable audit:
sudo find /var/log -type f -perm -002 > /var/tmp/world_writable_audit.txt
