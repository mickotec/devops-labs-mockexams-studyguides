🐧 LFCS Core Concepts Deep Dive: Network Bonding & Bridging

Network bonding provides hardware redundancy. Software bridges (br0) connect virtual guests directly to physical networks.

bond0 Mode 1 (active-backup): High availability failover Mode 4 (802.3ad LACP): Aggregates throughput /proc/net/bonding/bond0 # Check status LINUX SOFTWARE BRIDGE (br0) ip link add br0 type bridge && ip link set br0 up ip link set eth1 master br0 • Acts as an internal software L2 network switch. • Bridges VMs (KVM/QEMU) and containers onto host network.

🎯 Candidate Tasks
📌 Task 1: Create Linux Software Bridge
  1. Create a software bridge interface named br0 using ip link:

sudo ip link add br0 type bridge

  1. Assign IP address 192.168.100.1/24 to br0.
  2. Bring br0 interface UP.
📌 Task 2: Create Virtual Ethernet Pair (veth)
  1. Create a virtual ethernet pair named veth-host and veth-guest:

sudo ip link add veth-host type veth peer name veth-guest

📌 Task 3: Attach Slave Interface to Bridge
  1. Attach veth-host to bridge br0 as a master bridge port:

sudo ip link set veth-host master br0

  1. Bring veth-host and veth-guest interfaces UP:

sudo ip link set veth-host up

sudo ip link set veth-guest up

📌 Tasks & Official Solution
  1. Create bridge br0:

sudo ip link set br0 up

  1. Create veth pair:

sudo ip link add veth-host type veth peer name veth-guest

  1. Attach to bridge and bring up:

sudo ip link set veth-host master br0

sudo ip link set veth-host up

sudo ip link set veth-guest up
