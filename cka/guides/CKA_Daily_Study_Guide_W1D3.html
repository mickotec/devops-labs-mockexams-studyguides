☸ CKA Architectural Deep Dive: od Internals & YAML Architecture

A Pod is the smallest deployable computing unit in Kubernetes. Containers within a Pod share the network namespace (IP address and port space) and storage volumes.

  • Pause Container: Creates and holds the network and IPC namespaces. If an application container crashes and restarts, the IP address is preserved.
  • Inter-Container Communication: Containers in the same Pod communicate over localhost. They must not bind to the same network port.
  • RestartPolicy: Always (default for Pods/Deployments), OnFailure (Jobs), Never.

✅ Step-by-Step Grader Solution Walkthrough
📌 Tasks & Official Solution
  1. Create namespace:

kubectl create namespace fintech

  1. Fix /opt/k8s-manifests/broken-app.yaml:
apiVersion: v1
kind: Pod
metadata:
  name: transaction-processor
  namespace: fintech
spec:
  containers:
  - name: processor
    image: nginx:1.25-alpine
    env:
    - name: MAX_WORKERS
      value: "8"
    - name: CACHE_DIR
      value: "/tmp/cache"
    ports:
    - name: http
      containerPort: 8080
    - name: metrics
      containerPort: 9090
    resources:
      limits:
        memory: "128Mi"
        cpu: "200m"
    readinessProbe:
      httpGet:
        path: /
        port: 80
      initialDelaySeconds: 5

Apply: kubectl apply -f /opt/k8s-manifests/broken-app.yaml

  1. Deploy event-streamer:
kubectl run event-streamer -n fintech --image=busybox:1.36 --restart=Always -- \
  sh -c "while true; do echo '[STREAM] Transaction event at $(date)' >> /tmp/stream.log; sleep 5; done"
