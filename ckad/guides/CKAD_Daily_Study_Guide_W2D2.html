☸ CKAD Application Architecture Deep Dive: Week 2 Day 2 CKAD

ConfigMaps decouple application configuration from container images, storing non-confidential key-value pairs.

  • Single Key: Injected via configMapKeyRef into individual named environment variables.
  • Bulk Keys: Injected via envFrom.configMapRef to populate all keys as environment variables.

📌 Task 1: Create ConfigMap & Inject via envFrom
  1. In namespace ckad-w2d2, create a ConfigMap named backend-config with keys:
  • DB_HOST=postgres.internal
  • DB_PORT=5432
  • CACHE_TTL=3600
  1. Deploy Pod app-server using image busybox:1.36 sleeping continuously (sleep 3600).
  2. Inject ALL keys from backend-config into the container using envFrom.configMapRef.
  3. Also define an individual environment variable named APP_ENV with literal value "production" directly in spec.containers[0].env.

✅ Step-by-Step Grader Solution Walkthrough
📌 Tasks & Official Solution
📌 Official Solution: ConfigMaps & Env
ssh controlplane '
kubectl create configmap backend-config -n ckad-w2d2   --from-literal=DB_HOST=postgres.internal   --from-literal=DB_PORT=5432   --from-literal=CACHE_TTL=3600

cat << "EOF_POD" | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: app-server
  namespace: ckad-w2d2
spec:
  containers:
  - name: app
    image: busybox:1.36
    command: ["sleep", "3600"]
    env:
    - name: APP_ENV
      value: "production"
    envFrom:
    - configMapRef:
        name: backend-config
EOF_POD
'
