📌 Task 1: Mount Secret Volume with 0400 Permissions
  1. In namespace ckad-w2d4, create an Opaque Secret named api-credentials containing keys:
  • api-key: secret-alpha-9988
  • api-token: token-beta-7766
  1. Deploy Pod auth-consumer with image busybox:1.36 sleeping continuously (sleep 3600).
  2. Mount the Secret as a volume at /etc/api-keys with file permission mode 0400 (r--------).
  3. Ensure the file /etc/api-keys/api-key is readable and its permission mode is verified.

✅ Step-by-Step Grader Solution Walkthrough
📌 Tasks & Official Solution
📌 Official Solution: Secrets & Restricted Modes
ssh controlplane '
kubectl create secret generic api-credentials -n ckad-w2d4   --from-literal=api-key=secret-alpha-9988   --from-literal=api-token=token-beta-7766

cat << "EOF_POD" | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: auth-consumer
  namespace: ckad-w2d4
spec:
  volumes:
  - name: secret-vol
    secret:
      secretName: api-credentials
      defaultMode: 0400
  containers:
  - name: app
    image: busybox:1.36
    command: ["sleep", "3600"]
    volumeMounts:
    - name: secret-vol
      mountPath: /etc/api-keys
EOF_POD
'
