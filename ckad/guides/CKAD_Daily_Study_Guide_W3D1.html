🎯 Candidate Tasks
📌 Task 1: Sidecar Container Log Shipper
  1. In namespace ckad-w3d1, deploy a multi-container Pod named app-logger.
  2. Main container named app:
  • Image: busybox:1.36
  • Command: sh -c "while true; do echo 'TRANSACTION_ID='$(date +%s%N) >> /var/log/app/tx.log; sleep 2; done"
  • Mount volume log-storage at /var/log/app.
  1. Sidecar container named sidecar:
  • Image: busybox:1.36
  • Command: sh -c "tail -n+1 -F /var/log/app/tx.log"
  • Mount same volume log-storage at /var/log/app.
  1. Define volume log-storage as emptyDir: {}.
  2. Verify both containers are 2/2 Ready and kubectl logs app-logger -c sidecar outputs the transaction logs.

📌 Tasks & Official Solution
📌 Official Solution: Sidecar Log Streaming
ssh controlplane 'cat << "EOF_POD" | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: app-logger
  namespace: ckad-w3d1
spec:
  volumes:
  - name: log-storage
    emptyDir: {}
  containers:
  - name: app
    image: busybox:1.36
    command: ["sh", "-c", "while true; do echo 'TRANSACTION_ID='$(date +%s%N) >> /var/log/app/tx.log; sleep 2; done"]
    volumeMounts:
    - name: log-storage
      mountPath: /var/log/app
  - name: sidecar
    image: busybox:1.36
    command: ["sh", "-c", "tail -n+1 -F /var/log/app/tx.log"]
    volumeMounts:
    - name: log-storage
      mountPath: /var/log/app
EOF_POD
'
